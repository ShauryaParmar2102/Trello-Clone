# 📋 Trello Clone – Kanban Task Board

A responsive Kanban-style task management web application built using HTML, CSS and JavaScript.

Users can create tasks, select their priority, move tasks between different stages of the board, delete tasks and save their board in the browser.

---

## ✨ Features

- ➕ Add new tasks
- 🗂️ Choose which column a task belongs to
- 🔵 Low priority tasks
- 🟠 Medium priority tasks
- 🔴 High priority tasks
- 🖱️ Drag and drop tasks between columns
- 🗑️ Delete tasks
- 💾 Save tasks using Local Storage
- 🔄 Restore saved tasks when the page is refreshed
- 📭 Display an empty message when a column has no tasks
- 📱 Responsive mobile layout
- 💻 Desktop Kanban board layout

---

## 🗂️ Task Columns

The board contains five stages:

- 🕒 Later
- 📝 To Do
- 🚧 In Progress
- ⏸️ On Hold
- ✅ Finished

Tasks can be dragged between these columns as their status changes.

---

## 🛠️ Technologies Used

### 🌐 HTML
Used to create the structure of the task management dashboard.

### 🎨 CSS
Used to style the board, task cards, priority badges, buttons and responsive layout.

### ⚡ JavaScript
Used to provide the interactive functionality of the application, including:

- Creating tasks
- Deleting tasks
- Drag and drop
- DOM manipulation
- Event listeners
- Priority selection
- Updating empty column messages

### 💾 Local Storage
The browser's Local Storage API is used to save the current Kanban board so tasks can remain after the page is refreshed.

---

## 🖱️ How to Use

1. ✏️ Enter a task title.
2. 🗂️ Select the column for the task.
3. 🚦 Select a priority.
4. ➕ Click **Add**.
5. 🖱️ Drag the task between columns when its status changes.
6. 🗑️ Click the trash icon to delete a task.
7. 💾 Changes are automatically saved in the browser.

---

## 📥 How to Download and Run

###  Download ZIP

1. Open the project repository on GitHub.
2. Click the green **Code** button.
3. Select **Download ZIP**.
4. Extract the downloaded ZIP file.
5. Open the extracted project folder.
6. Open `index.html` in your web browser.

## 📱 Responsive Design

The application includes responsive styling for different screen sizes.

On desktop, the Kanban columns are displayed next to each other so the entire workflow can be viewed at once.

On smaller/mobile screens, the columns are displayed vertically to make tasks easier to read and manage.
